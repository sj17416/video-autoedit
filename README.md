# 유튜브 영상 자동 편집기

영상을 넣으면 아래 작업을 자동으로 하고, 완성본(`영상이름_편집본.mp4`, `.srt`)을 **이집트 폴더**에 저장합니다. 저장 위치는 웹앱 오른쪽 위에서 바꿀 수 있습니다.

| 단계 | 하는 일 |
|---|---|
| 1 음성 인식 | Whisper로 단어 단위 타이밍까지 받아적습니다. "자주 나오는 용어"를 등록하면 그 단어를 더 정확히 받아적습니다. |
| 2 컷 편집 | 무음과 필러워드("어", "음")를 잘라냅니다. 짧은 쉼과 호흡은 남겨 자연스럽게 하고, 받아적지 못한 말소리는 지우지 않습니다. 자막도 이때 만들어집니다. |
| 자막 교정 | Claude가 맞춤법, 인식 오류, 숫자 표기("이십만 원" → "20만 원")를 다듬습니다. 전체 자동 실행 때 자동으로 하며, 자막 탭에서 직접 고칠 수도 있습니다. |
| 3 장면 기획 | Claude가 설명 이미지를 넣을 순간을 고르고, 말로 나온 개인정보도 찾습니다. |
| 4 이미지 생성 | **오브젝트**(투명 배경 스티커)는 말하는 사람 옆, 얼굴 반대쪽에 톡 튀어나옵니다. **카드**는 화면 중앙에 뜨고 배경 영상이 살짝 어두워집니다. 둘 다 자막을 가리지 않게 배치됩니다. |
| 5 개인정보 스캔 | 화면의 전화번호, 주민번호, 이메일, 계좌번호, 주소, 차량번호 등을 모자이크합니다. |
| 6 최종 렌더링 | 컷, 이미지, 모자이크, **자막**, 삐 처리, **음량 평준화**(유튜브 권장 -14 LUFS)를 적용합니다. |

## 웹앱 (추천)

1. 바탕화면(또는 이집트 폴더)의 **`영상 자동 편집기`** 아이콘을 더블클릭하면 전용 창이 열립니다(검은 콘솔 창 없음, 이 PC에서만 접속 가능).
   - 예전 버전이 켜져 있으면 자동으로 새 버전으로 바꿔서 엽니다(작업 중일 때는 제외).
   - 끌 때는 오른쪽 위 **앱 종료**를 누르세요. 창만 닫으면 서버는 뒤에서 계속 켜져 있다가 다음 실행 때 바로 열립니다.
   - 문제가 생기면 `logs/server.log`에 기록이 남습니다. 아이콘을 다시 만들려면 `python tools/make_icon.py`를 실행하면 됩니다.
2. 왼쪽 **설정 (API 키)**에 Claude 키를 넣습니다(필수, 크레딧 필요). OpenAI 키를 넣으면 그림을 OpenAI 이미지 모델로 그립니다(선택).
3. 왼쪽 **그림체 참고 이미지**에 원하는 스타일의 그림을 올립니다(최대 4장).
4. **새 영상 올리기** → **▶ 전체 자동 실행**을 누릅니다. 진행 중에는 **중지** 버튼으로 멈출 수 있습니다.
5. 탭에서 결과를 다듬습니다.
   - **자막**: 글자와 시간을 고치고 **자막 저장**을 누릅니다. **Claude로 자막 교정**으로 다시 다듬을 수도 있습니다.
   - **장면 편집**: 종류, 위치, 크기, 시간, 캡션을 바꾸고 미리보기, 다시 그리기, 이미지 교체(실제 로고 PNG 등), 추가, 삭제를 할 수 있습니다.
   - **개인정보**: 모자이크나 삐 처리를 하지 않을 항목은 체크를 해제합니다.
6. **6 최종 렌더링**을 다시 누르면 수정 사항이 반영됩니다. **결과** 탭에서 재생하거나 **저장 폴더 열기**로 확인합니다.

**편집 설정**에서 다음을 바꿀 수 있습니다.
- 자막: 넣을지 여부, 스타일(외곽선 / 반투명 상자), 크기
- 음량 평준화
- 컷 강도
- 설명 이미지 빈도
- 자주 나오는 용어

## 속도 (Ryzen 5 5600G 실측)

2분짜리 4K 60fps 영상 기준으로 **전체 2분 53초**가 걸립니다(Claude 단계 제외).

| 항목 | 이전 | 지금 |
|---|---|---|
| 음성 인식 (60초 음성) | medium 89초 | **turbo 26초**, 더 정확함 |
| 개인정보 OCR (30초 구간) | 모든 프레임 디코딩 6.3초 | **키프레임만 1.1초** |
| 렌더링 | 4K60 원본 그대로 + x264 medium | **1080p·30fps + 빠른 인코딩**: 영상 길이의 0.7배 |
| 단계 진행 | 순서대로 | 기획·그림(인터넷)과 OCR(CPU)을 **동시에** |

- 4K 원본 그대로 받고 싶으면 옵션의 **속도 → 최고 화질**을 고르세요. 이때 4K 인코딩은 AMD 그래픽카드 하드웨어 인코더를 써서 2배 이상 빠릅니다.
- 컷 지점은 30fps 격자에 맞춰서, 속도 설정을 바꿔도 자막과 장면 시간이 어긋나지 않습니다.

## 쇼핑 쇼츠 만들기

직접 찍은 클립 몇 개와 대본을 넣으면 세로(1080x1920) 쇼핑 쇼츠를 만듭니다. 웹앱 왼쪽 **🛒 쇼핑 쇼츠 만들기** 칸에서 하거나 명령줄로 할 수 있습니다.

- **대본**: 한 줄 = 한 컷. 클립은 이름 순서대로 한 줄에 하나씩 붙습니다(`1_완성.mp4`, `2_재료.mp4` …). 특정 클립을 쓰려면 `파일이름.mp4 | 자막`처럼 적습니다.
  `키워드: 쫀득` 줄을 넣으면 그 단어가 노란색이 됩니다(안 적으면 촉촉·바삭·탱글·쫀득 중 대본에 나온 것).
- **자막**: 화면 가운데보다 살짝 아래, 흰 글자 + 검은 테두리, 한 줄 12자 이내. 키워드가 든 자막은 조금 더 크게.
- **컷**: 말이 2초를 넘는 줄은 같은 클립의 앞부분과 뒷부분으로 한 번 더 끊어서 1~2초마다 화면이 바뀝니다. 가로 영상도 세로로 꽉 차게 잘라 씁니다.
- **소리**: AI 목소리(무료 edge-tts, 인터넷 필요) + 클립의 실제 소리(작게) + 배경음악(선택, 더 작게) → 음량 평준화(-14 LUFS). 목소리를 `없음`으로 하면 클립 소리만 씁니다.
- 결과: 저장 위치에 `쇼핑쇼츠_<날짜>.mp4`와 `.srt`. **올리기 전에 꼭 직접 확인하세요.** 남이 찍은 영상은 쓰지 마세요(저작권 신고·수익 정지 위험).

```bash
python shop.py 내클립폴더 --bgm 음악.mp3 --voice 여성   # 폴더 안에 클립들과 대본.txt
```

## 드래그 앤 드롭 / 명령줄

영상을 **`영상편집.bat`** 위로 끌어다 놓으면 전체 과정을 한 번에 실행합니다. 이렇게 만든 프로젝트도 웹앱 목록에 나타나므로, 웹앱에서 이어서 수정할 수 있습니다.

```bash
python main.py 내영상.mp4 --vocab "복지로, 중위소득"
```

옵션은 `python main.py -h`로 확인할 수 있습니다.

## 참고

- 작업 파일은 `projects/` 폴더에 있습니다. 프로젝트를 삭제해도 원본 영상과 이집트 폴더의 완성본은 지워지지 않습니다.
- 렌더링 중에 실패하거나 중지해도 이전 완성본은 그대로 남습니다.
- 모든 처리는 CPU에서 돌아갑니다. 4K 영상은 렌더링이 오래 걸립니다.
- 유튜브는 사람 손이 거의 닿지 않은 반복적인 자동 생성 콘텐츠의 수익화를 제한합니다. 업로드 전에 꼭 확인하세요.
