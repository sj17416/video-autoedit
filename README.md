# 유튜브 영상 자동 편집기

영상을 넣으면 아래 작업을 자동으로 하고, 완성본(`영상이름_편집본.mp4`, `.srt`)을 **이집트 폴더**에 저장합니다. 저장 위치는 웹앱 오른쪽 위에서 바꿀 수 있습니다.

| 단계 | 하는 일 |
|---|---|
| 1 음성 인식 | Whisper로 단어 단위 타이밍까지 받아적습니다. "자주 나오는 용어"를 등록하면 그 단어를 더 정확히 받아적습니다. |
| 2 컷 편집 | 무음과 필러워드("어", "음")를 잘라냅니다. 짧은 쉼과 호흡은 남겨 자연스럽게 하고, 받아적지 못한 말소리는 지우지 않습니다. 자막도 이때 만들어집니다. |
| 자막 교정 | Claude가 맞춤법, 인식 오류, 숫자 표기("이십만 원" → "20만 원")를 다듬습니다. 전체 자동 실행 때 자동으로 하며, 자막 탭에서 직접 고칠 수도 있습니다. |
| 3 장면 기획 | Claude가 설명 이미지를 넣을 순간을 고르고, 말로 나온 개인정보도 찾습니다. |
| 4 이미지 생성 | **오브젝트**(투명 배경 스티커)는 말하는 사람 옆, 얼굴 반대쪽에 톡 튀어나옵니다. **카드**는 화면 중앙에 뜨고 배경 영상이 살짝 어두워집니다. 둘 다 자막을 가리지 않게 배치됩니다. |
| 5 개인정보 스캔 | 화면의 전화번호, 주민번호, 이메일, 계좌번호, 주소, 차량번호 등을 모자이크합니다. |
| 6 최종 렌더링 | 컷, 이미지, 모자이크, **자막**, 삐 처리, **음량 평준화**(유튜브 권장 -14 LUFS)를 적용합니다. |

## 웹앱 (추천)

1. 바탕화면(또는 이집트 폴더)의 **`영상 자동 편집기`** 아이콘을 더블클릭하면 전용 창이 열립니다(검은 콘솔 창 없음, 이 PC에서만 접속 가능).
   - 예전 버전이 켜져 있으면 자동으로 새 버전으로 바꿔서 엽니다(작업 중일 때는 제외).
   - 끌 때는 오른쪽 위 **앱 종료**를 누르세요. 창만 닫으면 서버는 뒤에서 계속 켜져 있다가 다음 실행 때 바로 열립니다.
   - 문제가 생기면 `logs/server.log`에 기록이 남습니다. 아이콘을 다시 만들려면 `python tools/make_icon.py`를 실행하면 됩니다.
2. 왼쪽 **설정 (API 키)**에 Claude 키를 넣습니다(필수, 크레딧 필요). OpenAI 키를 넣으면 그림을 OpenAI 이미지 모델로 그립니다(선택).
3. 왼쪽 **그림체 참고 이미지**에 원하는 스타일의 그림을 올립니다(최대 4장).
4. **새 영상 올리기** → **▶ 전체 자동 실행**을 누릅니다. 진행 중에는 **중지** 버튼으로 멈출 수 있습니다.
5. 탭에서 결과를 다듬습니다.
   - **자막**: 글자와 시간을 고치고 **자막 저장**을 누릅니다. **Claude로 자막 교정**으로 다시 다듬을 수도 있습니다.
   - **장면 편집**: 종류, 위치, 크기, 시간, 캡션을 바꾸고 미리보기, 다시 그리기, 이미지 교체(실제 로고 PNG 등), 추가, 삭제를 할 수 있습니다.
   - **개인정보**: 모자이크나 삐 처리를 하지 않을 항목은 체크를 해제합니다.
6. **6 최종 렌더링**을 다시 누르면 수정 사항이 반영됩니다. **결과** 탭에서 재생하거나 **저장 폴더 열기**로 확인합니다.

**편집 설정**에서 다음을 바꿀 수 있습니다.
- 자막: 넣을지 여부, 스타일(외곽선 / 반투명 상자), 크기
- 음량 평준화
- 컷 강도
- 설명 이미지 빈도
- 자주 나오는 용어

## 설치 (처음 한 번)

프로그램 폴더의 **`설치.bat`**을 더블클릭하세요. 이것만 하면 됩니다.

1. 파이썬 확인
2. 필요한 프로그램 설치 (이미 있으면 건너뜁니다)
3. 설치가 제대로 됐는지 확인
4. 아이콘 만들기
5. 바탕화면에 실행 아이콘 만들기

끝나면 바탕화면에 아이콘 3개가 생깁니다.

| 아이콘 | 하는 일 |
|---|---|
| 🎬 **영상 자동 편집기** | 영상 편집 화면을 엽니다 |
| 📷 **인스타 게시물 만들기** | 인스타 게시물 화면을 바로 엽니다 |
| 🛠 **영상 편집기 설치·복구** | 설치를 다시 합니다 (문제가 생겼을 때) |

앞의 두 아이콘은 같은 앱을 쓰므로, 하나가 켜져 있으면 다른 아이콘은 창만 새로 엽니다.

**잘 안 될 때**
- 파이썬이 없다고 나오면 [python.org](https://www.python.org/downloads/)에서 설치하세요. 설치 화면 맨 아래 **"Add python.exe to PATH"**를 꼭 체크해야 합니다.
- `DLL load failed` 같은 오류가 보이면 [Visual C++ 재배포 패키지](https://aka.ms/vs/17/release/vc_redist.x64.exe)를 설치한 뒤 `설치.bat`을 다시 실행하세요.
- 아이콘만 다시 만들려면 `바탕화면 아이콘 만들기.bat`을, 지우려면 `python tools/make_shortcut.py --remove`를 실행하세요.
- 패키지를 최신으로 올리려면 `python tools/setup.py --update`를 실행하세요.

## 인스타그램 게시물 만들기 · 자동 업로드

바탕화면의 **인스타 게시물 만들기** 아이콘, 또는 웹앱 오른쪽 위 **📸 인스타 게시물**을 누르면 열립니다(`http://127.0.0.1:5000/insta`).

1. **사진**: 내가 찍은 사진을 끌어다 놓거나(폴더째 가능), **내 영상에서 장면 가져오기**로 편집한 영상에서 선명한 장면을 뽑습니다. 같은(거의 같은) 사진은 자동으로 걸러집니다.
2. **작성 언어**: 한국어, 日本語, English, Français, Español, Português, Deutsch 중에서 고릅니다. 언어마다 Claude가 그 나라 사람에게 먹히는 후킹 제목과 본문을 따로 씁니다(직역이 아님). **스타일 샘플**을 넣으면 그 형식과 말투를 따릅니다.
3. **로고 · 카드 모양**: 브랜드 이름이나 로고 이미지, 로고 위치(왼쪽·가운데·오른쪽), 비율(1:1 / 4:5), 글자 크기, 그라데이션, 사진 높이를 정합니다. 제목의 `[대괄호]` 부분은 노란색으로 강조됩니다.
4. **▶ 게시물 만들기**: 선택한 사진 × 언어 수만큼 카드와 본문을 한 번에 만듭니다. 카드 합성은 이 PC에서 하므로 **그림 비용이 0원**입니다. Claude 글쓰기만 사진 1장 × 언어 1개에 약 10~20원이 듭니다(키가 없으면 직접 써도 됩니다).
5. **게시물**: 제목과 본문을 고치고 저장하면 카드가 바로 다시 만들어집니다. **다시 쓰기**, **본문 복사**, **다운로드**, **폴더에 저장**(저장 폴더/인스타_게시물)을 할 수 있습니다.
6. **자동 예약**: 계정을 연결한 뒤 게시물을 선택하고 **자동 예약**을 누르면, 계정별 언어·하루 개수·시간대에 맞춰 고르게 배치됩니다. **슬라이드로 묶어 예약**은 2~10장을 슬라이드 한 개로 올립니다. 앱이 켜져 있는 동안 30초마다 확인해서 올립니다.

**저작권 · 원본성**
- 남의 게시물을 캡처해 글씨, 그라데이션, 로고를 바꿔도 저작권법상 2차적저작물이라 침해입니다(저작권법 제22조).
- 인스타도 2026년 4월부터 이런 계정을 추천에서 뺍니다.
- 그래서 이 기능은 내 사진과 내 영상 장면만 쓰도록 만들었습니다. Claude가 캡처나 워터마크로 보이는 사진을 표시하고, 표시된 게시물은 '내 사진 맞음'을 체크해야 자동 업로드됩니다.

**계정 연결 (처음 한 번)**
- 공식 API(Instagram API with Instagram Login)만 씁니다. 아이디와 비밀번호로 앱을 흉내 내는 비공식 봇은 계정 정지 위험이 커서 쓰지 않습니다.
- 인스타 계정을 프로페셔널(크리에이터)로 전환하고, developers.facebook.com에서 비즈니스 유형 앱을 만듭니다. 그다음 'Instagram 로그인을 사용한 API 설정'에서 계정을 추가하고 **Generate token**으로 받은 토큰을 붙여 넣습니다. 자세한 순서는 화면 안의 '토큰 받는 방법'에 있습니다.
- 내 계정만 쓰는 앱은 앱 검수와 비즈니스 인증이 필요 없습니다. 토큰(60일)은 앱이 자동으로 연장합니다.
- 인스타 서버는 공개 인터넷 주소에서 이미지를 가져갑니다. 그래서 올리기 직전에 임시 호스팅(litterbox: 가입 없음, 1시간 뒤 삭제 / Cloudinary: 무료 계정)에 올립니다. 한쪽이 실패하면 다른 쪽으로 자동 전환합니다.
- API로 올린 사진 게시물에는 인스타 음악을 붙일 수 없습니다(공식 API 제한). 음악을 넣어 릴스 탭에 노출시키려면 **폴더에 저장**한 뒤 인스타 앱에서 직접 올리세요.
- 첫 게시물은 로그아웃한 브라우저에서 잘 보이는지 한 번 확인하세요. 해시태그는 인스타 규정상 5개까지입니다.

## 속도 (Ryzen 5 5600G 실측)

2분짜리 4K 60fps 영상 기준으로 **전체 2분 53초**가 걸립니다(Claude 단계 제외).

| 항목 | 이전 | 지금 |
|---|---|---|
| 음성 인식 (60초 음성) | medium 89초 | **turbo 26초**, 더 정확함 |
| 개인정보 OCR (30초 구간) | 모든 프레임 디코딩 6.3초 | **키프레임만 1.1초** |
| 렌더링 | 4K60 원본 그대로 + x264 medium | **1080p·30fps + 빠른 인코딩**: 영상 길이의 0.7배 |
| 단계 진행 | 순서대로 | 기획·그림(인터넷)과 OCR(CPU)을 **동시에** |

- 4K 원본 그대로 받고 싶으면 옵션의 **속도 → 최고 화질**을 고르세요. 이때 4K 인코딩은 AMD 그래픽카드 하드웨어 인코더를 써서 2배 이상 빠릅니다.
- 컷 지점은 30fps 격자에 맞춰서, 속도 설정을 바꿔도 자막과 장면 시간이 어긋나지 않습니다.

## 드래그 앤 드롭 / 명령줄

영상을 **`영상편집.bat`** 위로 끌어다 놓으면 전체 과정을 한 번에 실행합니다. 이렇게 만든 프로젝트도 웹앱 목록에 나타나므로, 웹앱에서 이어서 수정할 수 있습니다.

```bash
python main.py 내영상.mp4 --vocab "복지로, 중위소득"
```

옵션은 `python main.py -h`로 확인할 수 있습니다.

## 참고

- 작업 파일은 `projects/` 폴더에 있습니다. 프로젝트를 삭제해도 원본 영상과 이집트 폴더의 완성본은 지워지지 않습니다.
- 렌더링 중에 실패하거나 중지해도 이전 완성본은 그대로 남습니다.
- 모든 처리는 CPU에서 돌아갑니다. 4K 영상은 렌더링이 오래 걸립니다.
- 유튜브는 사람 손이 거의 닿지 않은 반복적인 자동 생성 콘텐츠의 수익화를 제한합니다. 업로드 전에 꼭 확인하세요.
