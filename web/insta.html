계정 연결 · 자동 업로드

+ 인스타 계정 추가
토큰 받는 방법 (처음 한 번, 약 10분)
  1. 인스타 앱 → 프로필 편집 → 프로페셔널 계정으로 전환(크리에이터). 계정은 공개여야 합니다.
  2. developers.facebook.com/apps → 앱 만들기. 사용 사례는 Instagram에서 메시지 및 콘텐츠 관리(없으면 '기타' → 유형 비즈니스). 비즈니스 포트폴리오는 '아직 연결 안 함'.
  3. 왼쪽 메뉴 Instagram → Instagram 로그인을 사용한 API 설정 → 필요한 권한 모두 추가 + instagram_business_content_publish.
  4. 액세스 토큰 생성에서 '계정 추가' → 인스타 로그인. 앱 역할에 '대기 중'이 보이면 인스타 앱 → 설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대 수락.
  5. 계정 옆 Generate token → 나온 토큰을 위 칸에 붙여 넣기 (60일짜리, 앱이 자동 연장).

내 계정만 쓰는 앱은 앱 검수·비즈니스 인증이 필요 없습니다.

인스타 서버가 공개 주소에서 이미지를 가져가므로, 올리기 직전에 임시 호스팅에 올렸다가 지웁니다.
