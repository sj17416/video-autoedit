# 블로그 주간 분석기

매주 블로그 데이터를 보고 **검색 유입이 늘면서 체류시간도 긴 글**을 찾아, 다음 할 일을 정리한 보고서를 만듭니다.

1. **뜨는 글**: 최근 2주 검색 클릭이 그 전 2주보다 20% 이상 늘었고, 체류시간이 블로그 중앙값보다 긴 글입니다.
2. **기존 글 보강**: 뜨는 글로 들어오는데 순위가 낮은 검색어를 보고, 그 글에 추가할 소제목을 제안합니다. 이 작업을 먼저 하세요.
3. **새 글 제안**: 같은 글을 다시 쓰는 게 아니라 **옆 검색어**로 넓히는 주제입니다(예: "수령 나이" 글이 뜨면 "조기수령 손해").
   예전에 제안한 주제와 이미 있는 글 제목은 빼고 제안합니다.
4. **초안**: 뜨는 글의 구조(소제목 수, 표, 길이)를 본떠 Claude가 씁니다. 노란 표시(`확인 필요`, `내 경험 추가`)를 고친 뒤 직접 발행하세요.

발행은 자동으로 하지 않습니다. 티스토리 Open API가 종료됐고, AI 글을 검토 없이 대량으로 올리면 Google 스팸 정책("대량 생성 콘텐츠 남용")에 걸려 블로그 전체 순위와 애드센스가 위험해지기 때문입니다.

결과는 `blog_growth/output/블로그이름/날짜/보고서.html`에 저장됩니다.

## 처음 한 번 설정 (30분 정도)

### 1. 블로그를 Search Console과 GA4에 연결
- **Search Console**(search.google.com/search-console)에서 블로그 주소를 **URL 접두어** 방식으로 추가합니다. 티스토리 관리 → 플러그인 → "구글 서치 콘솔" 플러그인으로 소유 확인을 하면 됩니다.
- **Google Analytics**(analytics.google.com)에서 속성을 만들고, 측정 ID(`G-`로 시작)를 티스토리 관리 → 플러그인 → "구글 애널리틱스" 플러그인에 넣습니다.
  GA4 **속성 ID**(숫자 9자리 정도, 관리 → 속성 설정에 있음)를 적어 두세요. 측정 ID(`G-...`)와 다릅니다.

### 2. 구글 서비스 계정 키 만들기
1. console.cloud.google.com에서 프로젝트를 하나 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 `Google Search Console API`와 `Google Analytics Data API`를 각각 **사용**으로 바꿉니다.
3. **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기**를 누릅니다(역할은 주지 않아도 됩니다).
4. 만든 계정의 **키 → 키 추가 → JSON**을 눌러 받은 파일을 `blog_growth/google_key.json`으로 저장합니다. 이 파일은 비밀번호와 같으니 남에게 주지 마세요(깃에는 올라가지 않게 해 두었습니다).
5. 서비스 계정 이메일(`...@...iam.gserviceaccount.com`)을 복사해서 두 곳에 추가합니다.
   - Search Console → 설정 → 사용자 및 권한 → 사용자 추가 (권한: 제한됨)
   - Google Analytics → 관리 → 속성 액세스 관리 → 추가 (역할: 뷰어)
   - 블로그가 두 개면 두 블로그 모두에 추가합니다.

### 3. 설정 파일
`config.example.json`을 복사해 `config.json`으로 이름을 바꾸고 블로그 주소, `search_console_site`(Search Console에 등록한 주소 그대로, 끝의 `/` 포함), GA4 속성 ID, 주제를 채웁니다.
Claude 키는 영상 편집기에서 쓰는 `.env`의 `ANTHROPIC_API_KEY`를 그대로 씁니다.

### 4. 설치와 확인
```
pip install -r requirements.txt
python -m blog_growth --dry-run
```
`--dry-run`은 Claude를 부르지 않고 데이터만 분석합니다(무료). 보고서가 나오면 연결이 된 것입니다.

## 실행
- 지금 한 번 실행: `blog_growth/블로그분석.bat` 더블클릭 (끝나면 보고서가 열립니다)
- **매주 월요일 오전 9시 자동 실행**: `blog_growth/주간예약등록.bat`을 한 번 더블클릭합니다. 그 시간에 PC가 꺼져 있었으면 다음에 켤 때 실행됩니다. 기록은 `logs/blog_growth.log`에 남습니다.
- 블로그 하나만: `python -m blog_growth --blog "건강 블로그"`

비용: 블로그 하나당 주제 기획 1번과 초안 2편으로, 주 1회면 Claude 사용료가 소액 듭니다. 초안 수는 `config.json`의 `drafts_per_week`로 바꿉니다.

**참고:** 글이 30개 미만이거나 블로그를 연 지 2~3개월이 안 됐으면 "뜨는 글 없음"이 정상입니다. 그동안은 계획한 주제대로 쓰세요.
